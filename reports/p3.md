This run verifies that the RoBERTa classifier contract, per-repository
training (via the shared runner), pooled training (P3-specific ablation),
metrics, resource profiling, and JSON artifact writing work end-to-end. It
uses a deliberately shrunk config (1 epoch, max_seq_length=64, 2 folds, one
repository) to run on a CPU-only dev machine in minutes rather than hours; it
is **not** representative of real model quality and is not comparable to any
reported benchmark. Artifacts will be stored in link: [`nlbse24/p3`](https://husteduvn-my.sharepoint.com/:f:/g/personal/anh_ln252275m_sis_hust_edu_vn/IgBPo-B9kMiXSbBPz0IOW0hQAZG_jkSOp-ELoIHUbe1h7vM?e=PAyrir).

A full 5-fold, all-repository run for both full fine-tuning and
LoRA, under both per-repository and pooled protocols, **is planned next** on
Kaggle GPU hardware, since full fine-tuning at max_seq_length=512 for 10
epochs is impractical on the current CPU-only dev machine.
